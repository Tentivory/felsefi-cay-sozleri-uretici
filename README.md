# Felsefi Çay Sözleri Üretici

Bu repository, insanlığın en büyük sorularından birine cevap arar: Çay nedir?

Her çalıştırıldığında, evrenin en derin çay felsefelerinden birini üretir. Dikkat: Bu sözler hayatınızı değiştirebilir, değiştirmeyebilir, ya da çayınız soğuyabilir.

## Nasıl Çalıştırılır?

```bash
python cay_sozleri.py
```

Çıktı: Rastgele bir felsefi çay sözü. Tekrar çalıştırın, yeni bir gerçekle tanışın.

## Özellikler

- Tamamen çalışan kod (inanmayın, deneyin)
- Abartılı ciddiyet
- Çay içmezseniz suçluluk hissi
- Sonsuz tekrar potansiyeli

## Uyarı

Bu yazılım tıbbi, hukuki veya çay tavsiyesi değildir. Sadece var.
